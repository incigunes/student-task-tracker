# Student Task Tracker

A modern and user-friendly task tracking web application built using HTML, CSS, and JavaScript.

## 🚀 Features

- Add tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks (All / Completed / Incomplete)
- Save tasks using localStorage
- Dark mode support
- Enter key support for quick task entry

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 💡 Description

This project is a beginner-friendly web application designed to help users manage their daily tasks efficiently. It features persistent storage using localStorage and includes a clean, modern interface with dark mode support.

## 📂 How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
